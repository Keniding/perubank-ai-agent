## Overview

PeruBank AI Agent is a **multi-agent AI system** designed for the Peruvian banking sector.
It leverages AMD Instinct MI300X GPUs with ROCm to run open-source LLMs (Llama 3.3 70B)
via vLLM, orchestrated through LangGraph to deliver intelligent banking services.

### Key Features

- **KYC Agent** - Automated identity verification with OCR
- **Risk Agent** - Credit scoring aligned with SBS regulations
- **Compliance Agent** - Real-time SBS/BCRP regulatory checks
- **Advisor Agent** - Personalized financial recommendations
- **Fraud Agent** - Real-time transaction fraud detection
- **Orchestrator** - Intelligent routing via LangGraph state machine

## Quick Start

### Prerequisites

- Python 3.13+ (managed via `uv`)
- Access to AMD Developer Cloud (MI300X)
- SSH key configured

### Installation

```bash
# Install uv (if not already installed)
# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

# Linux / Mac
curl -LsSf https://astral.sh/uv/install.sh | sh

# Clone the repository
git clone https://github.com/LEAD-team/perubank-ai-agent.git
cd perubank-ai-agent

# Create virtual environment with Python 3.13 and install all dependencies
uv sync

# Copy environment variables
cp .env.example .env
# Edit .env with your AMD Cloud endpoint
```

### Deploy vLLM on AMD MI300X

```bash
# SSH into your AMD Developer Cloud droplet
ssh root@<your-droplet-ip>

# Launch vLLM server
python -m vllm.entrypoints.openai.api_server \
    --model meta-llama/Llama-3.3-70B-Instruct \
    --tensor-parallel-size 1 \
    --max-model-len 32768 \
    --port 8000
```

### Run the Agent System

```bash
# Start the multi-agent system
uv run python -m src.main

# Or run the API server
uv run uvicorn src.api.app:app --host 0.0.0.0 --port 8080
```
